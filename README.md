## 功能

| 模块 | 说明 |
|---|---|
| 🚀 启动抢票 | 按配置自动抢购，支持多配置批量运行 |
| ⚙️ 生成配置 | 输入项目链接，自动拉取票档/购票人/地址，交互式生成配置 |
| 👤 账号登录 | 短信验证码登录，**全自动过极验验证码**，按手机号文件夹保存 Cookie |
| 🎫 购票信息 | 查询项目详情、票档、场次、实名认证购票人、收货地址 |
| 🔧 抢票设置 | 请求间隔、超时、重试策略等参数配置 |
| 🌐 代理设置 | 支持巨量代理 SOCKS5 动态 IP，自动获取/轮换/测试 |
| ⚙️ 系统设置 | 日志级别、运行参数调整 |



## 下载

| 文件 | 说明 |
|---|---|
| `bili_Ticker_test.exe` | 标准版（DirectML GPU 加速，需支持 DX12 的显卡） |
| `bili_Ticker_test_compat.exe` | 兼容版（CPU 推理，老显卡如 GTX 750 Ti 用这个） |

## 快速开始

1. 运行 `bili_Ticker_test.exe`（老显卡用 `_compat` 版）
2. 首次运行输入激活码（或申请试用）
3. 「账号登录」→ 短信登录，自动生成手机号文件夹
4. 「生成配置」→ 输入项目链接，选择票档/购票人/地址
5. 「启动抢票」→ 选择配置，开抢

## 环境要求

- Windows 10/11
- 标准版：支持 DirectX 12 的显卡
- 兼容版：无显卡要求，CPU 即可运行
